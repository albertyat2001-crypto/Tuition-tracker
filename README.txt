IMPORTANT INSTALL NOTE:
The app must be hosted on HTTPS (for example GitHub Pages) for Android PWA installation.
The "Install App" button is intentionally visible in the app. If the browser does not provide the automatic install prompt, the button shows the manual Chrome steps.

GitHub Pages:
1. Upload/replace ALL FIVE files in your repository root.
2. Commit changes.
3. Open the HTTPS GitHub Pages address in Chrome on Android.
4. Tap "📲 Install App", or Chrome menu -> Install app/Add to Home screen.

Before clearing browser/site data, use Backup Data because student/attendance/payment records are stored locally on the device.
